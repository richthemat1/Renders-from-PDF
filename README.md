# Фото из PDF

Программа для Windows, которая достаёт изображения из PDF-презентаций и раскладывает их по подписям и вариантам. Для каждого варианта получается один многостраничный PDF.

Работает на компьютере: презентации никуда не отправляются. Для запуска не нужны Python, аккаунт, подписка или интернет.

## Скачать и установить

**[Скачать установщик для Windows](https://github.com/richthemat1/Renders-from-PDF/releases/latest/download/PDF-Photos-Setup.exe)**

1. Скачайте `PDF-Photos-Setup.exe` и откройте его.
2. Следуйте шагам установки. Программа устанавливается для текущего пользователя, без прав администратора.
3. Запустите «Фото из PDF» из меню «Пуск». При установке можно добавить ярлык на рабочий стол.

Поддерживаются **Windows 10 и 11, 64-разрядные системы x64**. Для распознавания сканов нужен установленный русский пакет OCR Windows. Если его нет, программа сохранит скан целиком и сообщит об ограничении.

Если Windows покажет окно SmartScreen, проверьте, что файл скачан из этого репозитория. У программы пока нет платной цифровой подписи издателя.

### Без установки

[Скачать переносимую версию ZIP](https://github.com/richthemat1/Renders-from-PDF/releases/latest/download/PDF-Photos-Portable.zip), распаковать её в обычную папку и открыть `PDF-Photos.exe`. WinRAR не нужен: ZIP можно распаковать средствами Windows.

Все версии и описания изменений находятся в [разделе Releases](https://github.com/richthemat1/Renders-from-PDF/releases). Не нужно скачивать `Source code`: это исходники, а готовая программа лежит в файлах релиза.

## Как пользоваться

1. Перетащите одну или несколько PDF-презентаций (или папку с ними) из Проводника в окно программы — или нажмите **«Выбрать файлы»**.
2. Дождитесь завершения обработки.
3. Нажмите **«Открыть просмотр»**: откроется страница с изображениями, подписями и вариантами.
4. Проверьте распределение, особенно группы **«Без подписи»** и **«На проверку»**.
5. Если нужно, нажмите **«Редактировать»**: уберите лишнее, перенесите изображения в другой вариант или поменяйте порядок. Затем нажмите **«Сохранить»**. Там же можно переименовать вариант, папку или отдельный PDF.

Можно выбирать сразу несколько карточек с помощью Ctrl, Shift или флажков. Выбранные изображения можно убрать, перенести или перетащить вместе. Для открытия старой выгрузки используйте **«Открыть прошлый результат…»** в окне программы.

Во время сохранения кнопки редактора временно недоступны. Если закрыть программу в этот момент, она дождётся окончания записи. Старые файлы сохраняются в папке резервных копий.

Подробная инструкция — [«Как пользоваться»](Как%20пользоваться.txt).

## Что получится

Рядом с исходной презентацией появится отдельная папка:

```text
Презентация — PDF/
├── Вариант 1/
│   └── Вариант 1.pdf
├── Вариант 2/
│   └── Вариант 2.pdf
├── Все остальное/
│   ├── Без подписи/
│   ├── На проверку/
│   └── папки по другим подписям
├── Просмотр.html
└── Отчёт.json
```

В PDF варианта одна страница соответствует одному извлечённому изображению. Картинки идут в порядке презентации. Перспективное изображение без указанного варианта (ни в подписи, ни на странице, ни в разделе) относится к «Варианту 1». Изображения с другой подписью без номера варианта сохраняются отдельными PDF в папках по подписи внутри «Все остальное». Миниатюры и резервные копии лежат в скрытой папке `_Служебное`.

Исходный документ не меняется. Повторная обработка создаёт новую папку. Ручные правки заменяют только файлы готовой выгрузки, сохраняя прежние версии в `_Служебное/Резервные копии`.

## Как обновиться

Закройте программу, скачайте [последний установщик](https://github.com/richthemat1/Renders-from-PDF/releases/latest/download/PDF-Photos-Setup.exe) и установите его поверх предыдущей версии. Старую установленную версию заранее удалять не нужно. Уже обработанные презентации и папки результатов сохранятся.

Для переносимой версии распакуйте новый ZIP в новую папку и запускайте программу оттуда. Автоматической установки обновлений пока нет.

Ссылка на последнюю версию всегда одна: **https://github.com/richthemat1/Renders-from-PDF/releases/latest**. Её можно сохранить или отправить коллегам вместо архива с каждым обновлением.

## Что учитывать

- Программа извлекает растровые изображения: кроме рендеров, в результат могут попасть схемы, карты и логотипы. Лишнее можно убрать в редакторе.
- Подписи определяются автоматически. Необычная вёрстка и ошибки OCR могут потребовать ручной проверки.
- Простые фотографии внутри сканов разделяются автоматически; сложные коллажи могут сохраниться целиком.
- Чисто векторные иллюстрации отдельно не извлекаются.
- Загрузка файлов в админку не выполняется: программа готовит локальные материалы.
